# MyShot לאנדרואיד

[English](README.md)

זו האפליקציה המלאה, כולל מסך הבית, התרופות, התזונה, התוספים, הקבלות, תמונות ההתקדמות ודוח הרופא. היא עטופה ב-Capacitor 8 כאפליקציית אנדרואיד, ונוספו לה תזכורות אמיתיות של הטלפון.

## הדרך הקצרה לקובץ APK

### אפשרות 1: GitHub בונה בשבילכם

כל push לענף `main` בונה APK אוטומטית:

1. נכנסים ל-[Actions](https://github.com/Ranjacobi/MyShot/actions) ופותחים את ההרצה האחרונה של **Build Android APK**.
2. תחת Artifacts מורידים את **MyShot-apk** ופותחים את ה-zip.

כל בנייה מתפרסמת גם תחת [Releases](https://github.com/Ranjacobi/MyShot/releases). בטלפון, הקישור הזה מוריד תמיד את ה-APK החדש ביותר (צריך להיות מחוברים ל-GitHub, כי המאגר פרטי):
https://github.com/Ranjacobi/MyShot/releases/latest/download/MyShot.apk

אפשר להפעיל את הבנייה גם ידנית: Actions ← Build Android APK ← Run workflow.

כדאי שהמאגר יהיה פרטי. מי שמחזיק את מפתח החתימה (`ci/debug-signing.p12`) יכול לחתום APK שיותקן כעדכון של MyShot.

### אפשרות 2: על המחשב, בפקודה אחת

צריך Node.js 22 ומעלה ו-Android Studio שנפתח לפחות פעם אחת:

- **מק או לינוקס:** `./build-apk.sh`
- **ווינדוס:** `build-apk.cmd`

בסוף נוצר `MyShot.apk` בתיקיית הפרויקט.

### התקנה בטלפון

1. מעבירים את `MyShot.apk` לטלפון, דרך Drive, וואטסאפ או כבל.
2. פותחים את הקובץ ומאשרים ״התקנה מאפליקציות לא מוכרות״ לאפליקציה שממנה פתחתם אותו.
3. אם Play Protect מזהיר על מפתח לא מוכר, בוחרים ״להתקין בכל זאת״.

**עדכונים:** כל קובץ שנבנה ב-GitHub חתום באותו מפתח (`ci/debug-signing.p12`), ולכן מתקינים אותו על הגרסה הקודמת והנתונים נשמרים. קובץ שנבנה על המחשב חתום במפתח אחר, ואנדרואיד יסרב להתקין אותו על גרסה מ-GitHub, או להפך. לכן לא מערבבים את שתי הדרכים באותו טלפון. אם בכל זאת צריך לעבור, מייצאים קודם גיבוי, מסירים, מתקינים ומייבאים.

### גרסה חתומה ל-Google Play (לא חובה)

ה-APK שלמעלה מיועד להתקנה ישירה. לחנות צריך קובץ AAB חתום במפתח הפצה משלכם:

1. יוצרים מפתח, פעם אחת, ושומרים אותו בגיבוי — בלעדיו אי אפשר לעדכן את האפליקציה בחנות:
   ```bash
   keytool -genkeypair -keystore myshot-release.jks -alias myshot -keyalg RSA -keysize 2048 -validity 10000
   ```
2. ב-GitHub, תחת Settings ← Secrets and variables ← Actions, מוסיפים ארבעה סודות:
   - `ANDROID_KEYSTORE_BASE64`: תוכן הקובץ בקידוד base64. במק: `base64 -i myshot-release.jks | pbcopy`
   - `ANDROID_KEYSTORE_PASSWORD`
   - `ANDROID_KEY_ALIAS`: אצלנו `myshot`
   - `ANDROID_KEY_PASSWORD`
3. מההרצה הבאה, תחת Artifacts יופיע גם `MyShot-release`, ובו APK ו-AAB חתומים.

את קובץ המפתח עצמו לא מכניסים למאגר. ה-`.gitignore` כבר מסנן קבצי `.jks`.

## גרסה

מספר הגרסה נמצא במקום אחד: `APP_VERSION` בקובץ `www/index.html`. בכל בנייה הסקריפט `scripts/patch-android.mjs` מעתיק אותו לאנדרואיד בתור `versionName`. הוא גם מחשב ממנו `versionCode` (ראשי × 10000 + משני × 100 + תיקון, כלומר 1.4.0 ← 10400), כך שכל גרסה גבוהה מהקודמת. גם הכותרת של כל Release כוללת את מספר הגרסה.

כדי להוציא גרסה חדשה מעלים את `APP_VERSION`, מוסיפים שורה בראש `CHANGELOG` באותו קובץ (היא מופיעה במסך ״אודות״ באפליקציה), ועושים push.

## מה יש בפרויקט

| קובץ או תיקייה | מה זה |
|---|---|
| `www/index.html` | האפליקציה עצמה. כאן עורכים כשרוצים לשנות משהו |
| `capacitor.config.json` | שם האפליקציה, מזהה החבילה והגדרות התוספים |
| `assets/` | אייקון ומסכי פתיחה, שמהם נוצרים כל הגדלים לאנדרואיד |
| `resources/android/` | אייקון ההתראות לשורת הסטטוס |
| `scripts/patch-android.mjs` | מוסיף את הרשאות ההתראות ובודק את גרסת ה-SDK |
| `store/` | אייקון 512 ותמונת הנושא (1024×500) לדף בחנות |
| `.github/workflows/build-apk.yml` | הבנייה בענן של GitHub |
| `build-apk.sh`, `build-apk.cmd` | בנייה על המחשב בפקודה אחת |
| `ci/debug-signing.p12` | מפתח חתימה קבוע לגרסאות הבדיקה, כדי שעדכונים יותקנו על הקודמים |

## בנייה בפעם הראשונה

צריך Node.js בגרסת LTS עדכנית ו-Android Studio עדכני. הפקודות רצות מתוך התיקייה של הפרויקט:

```bash
npm install
npx cap add android
node scripts/patch-android.mjs
npx capacitor-assets generate --android
npx cap sync android
npx cap open android
```

אפשר להריץ את ארבע הפקודות האמצעיות גם בפקודה אחת: `npm run android:init`.

ב-Android Studio מחברים טלפון בכבל, עם ניפוי באגים ב-USB מופעל, ולוחצים Run.

## אחרי שינוי באפליקציה

עורכים את `www/index.html`, ואז:

```bash
npx cap sync android
```

## העלאה ל-Google Play

1. **גרסת SDK:** Google Play דורש מאפליקציות חדשות ומעדכונים לטרגט Android 16 (API 36). הסקריפט בודק את זה ומזהיר אם הגרסה נמוכה יותר.
2. **מזהה החבילה:** הוא `com.itranstudios.myshot`. אם רוצים מזהה אחר, משנים אותו ב-`capacitor.config.json` לפני `npx cap add android`, כי אחרי ההעלאה הראשונה לחנות אי אפשר לשנות אותו.
3. **בנייה חתומה:** ב-Android Studio בוחרים Build ← Generate Signed App Bundle, ומעלים את קובץ ה-AAB. את קובץ המפתח (keystore) שומרים בגיבוי — בלעדיו אי אפשר לעדכן את האפליקציה.
4. **טופס Data safety:** כל הנתונים נשמרים בטלפון בלבד. אם מוגדר מפתח בינה מלאכותית, תמונות ותיאורי ארוחות שהמשתמש בוחר לנתח נשלחים לספק שנבחר: Anthropic, OpenAI או Google.
5. **מדיניות בריאות:** כדאי לעבור על מדיניות Google Play לאפליקציות בריאות. האפליקציה היא יומן אישי ומציגה הסתייגות רפואית, אבל הטפסים בקונסולה שואלים על זה.

## תזכורות

הן מתוזמנות בטלפון עצמו, ומגיעות גם כשהאפליקציה סגורה ובלי אינטרנט. אחרי כל תיעוד הן מתעדכנות, כך שאם כבר סימנתם — תזכורת המעקב לא תגיע.

- **מנה או הזרקה:** בזריקה שבועית ביום ובשעה הקבועים. בכדור יומי כל יום בשעה שנבחרה. בקסניקל עם כל ארוחה.
- **אם לא תועד:** כמה שעות אחרי המועד, ובכדורים על קיבה ריקה כבר אחרי שעה. אם יש איחור בזריקה שבועית, מגיעה תזכורת יומית עד שעובר הזמן שבו עוד אפשר להזריק.
- **ערב לפני** (שבועי), **תוספים** לפי שעות הבוקר, הצהריים, הערב והלילה, **מים**, **שקילה שבועית** ו**מלאי** (מלאי נמוך, ועט שעומד לפוג).
- **כפתורים בהתראה:** ״תיעדתי״ רושם את המנה מיד, ובזריקה עם האזור המומלץ. ״בעוד שעה״ דוחה את התזכורת. בתוספים יש ״לקחתי הכול״.

מנהלים הכול במסך **עוד ← תזכורות**: מפעילים ומכבים כל סוג, קובעים שעות, מוסיפים תזכורות משלכם (פעם אחת, כל יום, בימים מסוימים או כל חודש), רואים מה מתוכנן בקרוב ושולחים התראת ניסיון. יש גם תזכורת גיבוי שבועית, עם כפתור ״גיבוי עכשיו״.

**הרשאות:** בהפעלה הראשונה האפליקציה מבקשת הרשאה להתראות. באנדרואיד 14 ומעלה, תזכורת בשעה המדויקת דורשת אישור נוסף — יש לו כפתור בהגדרות. בלי האישור, אנדרואיד עלול לעכב תזכורת בכמה דקות.

**חיסכון בסוללה:** חלק מהיצרנים (למשל שיאומי, ובחלק מהמכשירים גם סמסונג) עוצרים התראות של אפליקציות ״רדומות״. אם תזכורת לא מגיעה, כדאי להוציא את MyShot מרשימת החיסכון בסוללה.

## בינה מלאכותית באפליקציה (לא חובה)

באנדרואיד, הצילום עובר דרך המצלמה של הטלפון באמצעות התוסף הרשמי של Capacitor. הוא מקטין את התמונה ומחזיר אותה גם אם אנדרואיד סגר את האפליקציה בזמן הצילום. אחרי זיהוי אפשר לערוך כל מאכל בכפתור ״עריכה״, או ללחוץ ״צילום מחדש״ כדי להחליף את הזיהוי האחרון.

צילום קבלות, ניתוח ארוחה מתמונה, תווית מזון ורעיונות לארוחות עובדים עם מפתח API אישי של אחד משלושה ספקים. בוחרים ספק בהגדרות ← בינה מלאכותית, מדביקים מפתח ובודקים עם ״בדיקת החיבור״.

| ספק | איפה יוצרים מפתח | מודלים ברירת מחדל (תמונות / רעיונות) |
|---|---|---|
| Claude (Anthropic) | console.anthropic.com | `claude-sonnet-5-5` / `claude-haiku-5-5` |
| ChatGPT (OpenAI) | platform.openai.com/api-keys | `gpt-6-sol` / `gpt-6-luna` |
| Gemini (Google) | aistudio.google.com/apikey | `gemini-3.5-flash-lite` / `gemini-3.5-flash-lite` |

אפשר לקבוע מודל אחר לכל ספק באותו מסך, למשל כשיוצא מודל חדש. השימוש ב-API בתשלום, לפי התעריף של הספק.

במפתח חינמי של Gemini המכסה במודלים הגדולים נמוכה מאוד, לדקה וליום, ולכן ברירת המחדל היא Flash-Lite. אם בוחרים מודל Gemini גדול יותר והוא מגיע למגבלה או לא עונה תוך 40 שניות, האפליקציה מנסה שוב פעם אחת עם Flash-Lite.

המפתחות נשמרים רק בטלפון, אחד לכל ספק, ולא נכללים בגיבוי. תמונה נשלחת לספק שנבחר רק כשמבקשים לנתח אותה. בלי מפתח האפליקציה עובדת כרגיל, רק בלי ניתוח התמונות.

**לפרסום ציבורי** זה לא הפתרון הנכון: לא כדאי לבקש מכל משתמש מפתח משלו, ואסור לשים מפתח שלכם בתוך האפליקציה. במקרה כזה צריך שרת קטן שמחזיק את המפתחות ומעביר את הבקשות, וזה שינוי בפונקציה `aiClient` ב-`www/index.html`.

הנתונים נשמרים בטלפון בלבד. הסרת האפליקציה או ״ניקוי נתונים״ בהגדרות אנדרואיד מוחקים אותם, ולכן כדאי לגבות.

- **גיבוי ל-Google Drive:** בהגדרות לוחצים ״גיבוי ל-Google Drive״. נפתח חלון השיתוף של אנדרואיד, ובוחרים בו Drive ואת התיקייה.
- **שחזור:** לוחצים ״שחזור מגיבוי״ ובוחרים את הקובץ מתוך Drive. אפשר לשחזר גם מגיבוי של הגרסה ב-claude.ai.
- **תזכורת שבועית:** במסך התזכורות מפעילים ״גיבוי שבועי״. בהתראה יש כפתור ״גיבוי עכשיו״.
